# Controls — Medieval Blood Arena

## Desktop Controls (Default — Rebindable in Settings / Controls)

| Action | Default Input | Description |
| :--- | :--- | :--- |
| Move | `W` `A` `S` `D` | Physical foot-driven locomotion relative to camera |
| Camera Look & Aim | `Mouse` (Pointer Lock in combat) | Rotate camera and aim weapon swing direction |
| Right-Hand Attack / Swing | `Left Mouse Button` (Hold + Drag or Click) | Drives right arm swing along mouse direction; double-tap or forward click for thrust |
| Defensive Guard / Parry | `Right Mouse Button` (Hold) | Raises off-hand shield or angles primary weapon into high guard parry |
| Left Hand Grab / Release | `Q` | Toggle off-hand grip, grab nearby weapon/shield, or release |
| Right Hand Grab / Release | `E` | Toggle primary-hand grip, pick up dropped weapon, or swap |
| Jump / Lunge Step | `Space` | Upward leg impulse / forward lunge step |
| Recover / Reset | `R` | Pick up nearest dropped weapon in combat, or reset Training session |
| Pause Menu | `Tab` or `Esc` | Pause simulation and open pause menu |

## Mobile & Touch Controls
- **Left Virtual Joystick**: Smooth analog movement and directional stepping.
- **Right Touch Area**: Drag to rotate camera and steer weapon guard/aim.
- **Attack Button**: Hold & drag or tap to execute physical slashes and thrusts.
- **Defend Button**: Hold to raise shield or weapon guard.
- **L-Hand / R-Hand Buttons**: Grab, release, or pick up dropped weapons.
- **Jump & Recover Buttons**: Lunge/jump or recover dropped weapon.
